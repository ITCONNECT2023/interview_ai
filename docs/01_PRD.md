# 인터뷰 전사·기사 초안 서비스 PRD

## 문제

기자는 인터뷰 후 음성을 반복 재생하며 발언을 옮기고, 기사에 쓸 대목과 검증할 사실을 따로 정리해 초안을 작성한다. 이 과정은 오래 걸리고 인용문이 원문과 달라지거나 불확실한 내용을 사실처럼 쓰는 오류가 생기기 쉽다. 본 서비스는 **음성에 있는 내용만 근거로** 검토 가능한 전사·취재 데이터·기사 초안을 제공해 취재 정리와 초안 작성 시간을 줄인다.

## 대상 사용자

- 1차 사용자: 인터뷰를 직접 취재하고 기사 구조를 잡는 기자
- 2차 사용자: 전사·인용·사실관계를 검토하는 데스크 및 편집자
- 전제: 사용자는 자동 생성 결과를 그대로 발행하지 않고 원음과 대조해 최종 판단한다.

## 사용자 시나리오

1. 기자가 10분 이내의 인터뷰 음성 파일을 업로드한다.
2. 시스템이 파일 조건을 확인하고, 화자별·타임코드별 전사를 생성한다.
3. 시스템이 전사만 분석해 핵심 발언, 인용문 후보, 사실 정보, 확인 필요 항목을 분리한다.
4. 기자가 인용문 후보의 원문 위치를 눌러 해당 전사와 음성 구간을 대조한다.
5. 시스템이 리드 3안, 본문 구조와 완성 문장형 기사 초안을 생성하고 모든 문장을 근거 전사에 연결한다.
6. 기자가 원음과 초안을 대조·검토한 뒤 복사하거나 CMS 데스크 검토함으로 송고한다. 시스템은 자동 발행하지 않는다.

## 입력·처리·출력

| 구분 | 요구사항 |
|---|---|
| 입력 | `mp3`, `m4a`, `wav` 형식의 인터뷰 음성 1개, 재생 시간 10분·파일 크기 100MB 이내와 취재 메타데이터·자료 처리 동의 |
| 입력 검증 | 형식·재생 시간·용량·손상 여부를 업로드 시 확인하며, 조건을 벗어난 파일은 분석하지 않고 사유와 재업로드 방법을 안내 |
| 처리 | 음성 인식 → 화자 분리(Speaker diarization) → 구간별 타임코드 부여 → 전사 기반 정보 분류 → 전사 원문과 결과 항목 연결 |
| 전사 | 화자 라벨과 시작·종료 타임코드가 붙은 구간별 원문. 화자는 `화자 A`, `화자 B`로 표시하며 신원을 추정하지 않음. 들리지 않는 부분은 `[불명확]`으로 표시 |
| 핵심 발언 | 기사 판단에 중요한 발언을 요약하되, 각 항목에 근거 전사 구간을 연결 |
| 인용문 후보 | 전사 문구를 임의로 고치지 않은 직접 인용 후보와 화자 라벨, 원문 위치(타임코드 및 전사 구간 ID)를 함께 표시 |
| 사실 정보 | 전사에 명시된 인물·기관·수치·날짜·장소·사건 등 검증 가능한 주장과 근거 위치를 구조화 |
| 확인 필요 항목 | 잘 안 들림, 화자 불명확, 표현 모호, 수치·고유명사 불확실, 상충 발언 등 기자 확인이 필요한 내용과 사유·근거 위치를 표시 |
| 리드 3안 | 전사에 근거한 `사실형`, `인용형`, `이슈형` 각 1안. 새로운 배경이나 해석을 추가하지 않으며 근거 구간을 연결 |
| 본문 구조 | 권장 섹션 순서, 각 섹션의 핵심 주제, 사용할 발언·사실·확인 필요 항목의 참조 ID를 제공 |
| 기사 초안 | 선택한 리드와 본문 구조를 완성 문장으로 구성하되 모든 문단·수치·인용에 전사 근거 ID를 연결하고 불확실성은 `[확인 필요]`로 유지 |
| 송고 | 검토된 초안을 CMS의 데스크 검토함으로 전송. 사용자 확인 없이 자동 송고·자동 발행하지 않음 |

## 범위

- 음성 1개·취재 메타데이터 업로드, 공개 범위 선택, 자료 처리 동의 및 입력 조건 검증
- 인터뷰 음성의 자동 전사, 화자 구분, 타임코드 표시
- 전사 구간별 고유 ID 부여와 결과 항목의 원문 근거 연결
- 전사 직접 편집·원문 복원·구간 분할·검토 상태 저장과 전사 결과 내보내기
- 필수 결과 8종 생성: 전사, 핵심 발언, 인용문 후보, 사실 정보, 확인 필요 항목, 리드 3안, 본문 구조, 기사 초안
- 결과 화면에서 전사 검색·이동, 인용 근거 확인, 음성 구간 재생, 초안 복사
- 사용자 확인을 거친 CMS 데스크 검토함 송고와 송고 기록 저장
- 처리 실패 또는 일부 식별 실패 시 원인과 영향을 명시

## 제외 범위

- 전사에 없는 내용 생성, 외부 배경 정보·상식·검색 결과 추가
- 사용자 확인 없는 자동 송고, CMS 자동 발행, 대외 공개
- 화자의 실명·직책·소속·관계 추정
- 들리지 않는 구간, 끊긴 문장, 불명확한 수치·고유명사의 임의 보완, 문맥상 추정·전문 용어 자동 교정
- 외부 자료를 이용한 사실 확인, 맞춤법을 이유로 한 인용문 의미 변경
- 10분 초과 파일, 여러 파일 일괄 처리, 실시간 녹음·전사, 번역

## 성공 기준

| 기준 | 출시 판단 조건 |
|---|---|
| 입력 통제 | 지원 형식·10분·100MB 이하 파일은 접수되고, 그 외 파일은 분석 전에 차단되며 사유가 표시됨 |
| 필수 결과 완결성 | 정상 처리 건의 100%에서 필수 결과 8종과 화자·타임코드 전사가 모두 표시됨 |
| 근거 추적성 | 핵심 발언·인용문 후보·사실 정보·확인 필요 항목·리드·본문 구조·기사 초안의 모든 항목이 하나 이상의 전사 구간 ID로 연결됨 |
| 인용 정확성 | 인용문 후보 텍스트가 연결된 전사 원문과 문자 단위로 일치함. 생략이 있으면 생략 부호와 범위를 명시함 |
| 불확실성 보존 | 청취 불가·불명확 구간이 추정 문구로 채워진 사례 0건이며 `[청취 불가]`, `[불명확]`, `[확인 필요]`로 표시됨 |
| 금지 사항 준수 | 평가용 음성 세트에서 전사 외 내용·배경 정보·화자 신원 추정·불명확 구간 임의 보완 사례 0건 |
| 사용성 | 사용자가 인용문 후보에서 원문 전사와 해당 음성 구간으로 1회 동작 안에 이동 가능 |
| 송고 통제 | CMS 송고 전 대상·초안 버전·미해결 항목을 확인하며 자동 발행 사례 0건 |

## 자료 취급 원칙

- 업로드 전에 사용자가 음성 처리에 필요한 권한과 동의를 확보했음을 확인한다.
- 음성·전사·분석 결과는 해당 작업 처리와 사용자 검토에만 사용하며, 모델 학습이나 제3자 제공에 재사용하지 않는다.
- 전송 구간과 저장 구간을 암호화하고, 작업별 접근 권한을 분리하며, 접근·삭제 기록을 남긴다.
- 원본 음성·전사·분석·초안·내보내기 파일은 생성일부터 최대 30일 보관 후 자동 삭제한다. 사용자는 그 전에 직접 삭제할 수 있으며 삭제 요청 시 원본·파생본·캐시를 함께 제거한다.
- 결과는 자동 생성 보조 자료임을 표시한다. 최종 인용·사실 확인·초안 검토·송고·발행 책임은 사용자에게 있으며, 불확실한 내용은 원음 확인 전까지 확정 정보로 취급하지 않는다.
