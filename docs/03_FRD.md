# 인터뷰 전사·기사 초안 서비스 기능 요구사항 문서(FRD)

> 기준: 사용자 승인 내용을 반영해 `docs/01_PRD.md`, 본 FRD와 `design` 시안의 범위를 정합화했다. 외부 자료 대조·팩트체크 전송과 문맥상 추정·전문 용어 자동 교정은 제외한다. 전사 중 화면은 별도 화면으로 정의하고 두 전사 검토 시안은 하나의 반응형 화면으로 통합한다. 화자는 신원을 추정하지 않고 `화자 A`, `화자 B`로만 표시한다.

## 3) 기능 상세

### F-01 음성 파일 선택 및 검증

- 사용자 행동: 파일을 끌어다 놓거나 파일 찾기로 음성 파일 1개를 선택한다.
- 입력: `.mp3`, `.m4a`, `.wav` 파일 1개.
- 처리 규칙: 확장자·MIME·재생 가능 여부·10분 이하·100MB 이하를 순서대로 검사한다. 한 번에 한 파일만 허용하며 분석 전까지 원본을 변경하지 않는다.
- 출력: 파일명, 형식, 재생 시간, 용량과 검증 성공 상태.
- 오류 상태: 미지원 형식, 10분 초과, 100MB 초과, 손상·암호화·빈 파일, 다중 선택 시 항목별 사유와 허용 조건을 표시한다.
- 완료 조건: 모든 검증을 통과한 파일이 업로드 대기 상태로 등록된다.

### F-02 취재 메타데이터 입력

- 사용자 행동: 취재·보도 건명, 취재원 식별자, 담당 기자, 출입처·부처, 녹음 일시를 입력한다.
- 입력: 입력 항목 표의 취재 메타데이터.
- 처리 규칙: 필수값과 길이만 검증하며 메타데이터를 전사 내용 생성, 화자 신원 추정, 배경 정보 보완에 사용하지 않는다.
- 출력: 업로드 작업에 연결된 메타데이터 요약.
- 오류 상태: 필수값 누락·길이 초과·잘못된 날짜 형식은 해당 입력란 아래에 표시한다.
- 완료 조건: 필수값이 유효하게 저장된다.

### F-03 공개 범위 및 자료 처리 동의

- 사용자 행동: 발언 공개 범위를 선택하고 자료 처리 동의에 체크한다.
- 입력: 공개 범위 1개, 동의 여부.
- 처리 규칙: 공개 범위는 작업 메타데이터로만 저장한다. 원본·전사·분석·초안의 최대 30일 보관과 사용자 즉시 삭제 권리를 동의 전에 고지하며, 동의 전에는 파일 전송과 분석 시작 버튼을 비활성화한다.
- 출력: 선택된 보도 조건, 30일 자동 삭제 예정과 동의 완료 상태.
- 오류 상태: 동의하지 않고 진행하면 동의가 필요하다는 안내를 표시한다.
- 완료 조건: 공개 범위가 선택되고 필수 동의가 완료된다.

### F-04 분석 옵션 설정

- 사용자 행동: 인용문 및 사실·확인 필요 항목 자동 추출 여부를 선택한다.
- 입력: 화자 분리, 인용문 추출, 사실·확인 필요 항목 추출 옵션.
- 처리 규칙: 화자 분리는 항상 적용한다. 전문 용어 자동 교정, 문맥상 추정, 외부 자료 대조, 팩트체크 전송 옵션은 제공하지 않는다.
- 출력: 이번 작업에 적용할 옵션 요약.
- 오류 상태: 필수 화자 분리 옵션이 비정상적으로 해제되면 다시 켜고 이유를 안내한다.
- 완료 조건: 허용된 옵션 조합이 작업 설정에 저장된다.

### F-05 파일 업로드 및 진행 표시

- 사용자 행동: 전사 및 분석 시작을 누른다.
- 입력: 검증된 파일, 유효한 필수 메타데이터, 동의, 분석 옵션.
- 처리 규칙: 업로드 작업 ID를 만들고 중복 클릭을 차단한다. 전송 중 파일명과 전송률을 표시하며 완료 전 다음 화면 이동을 막는다.
- 출력: 대기·업로드 중·업로드 완료 상태와 0~100% 진행률.
- 오류 상태: 네트워크 단절, 서버 용량 부족, 인증 만료, 업로드 시간 초과 시 원인과 재시도 가능 여부를 표시한다.
- 완료 조건: 서버가 파일 무결성을 확인하고 업로드 완료 응답과 작업 ID를 반환한다.

### F-06 업로드 결과 및 다시 하기

- 사용자 행동: 업로드 결과를 확인하고 계속, 재시도, 파일 교체 중 하나를 선택한다.
- 입력: 업로드 상태와 작업 ID.
- 처리 규칙: 성공 시 전사 중 화면으로 이동한다. 재시도는 동일 파일·메타데이터를 유지하고, 파일 교체는 기존 선택을 폐기하되 입력 메타데이터는 유지한다.
- 출력: 업로드 완료 요약 또는 조치 가능한 오류 안내.
- 오류 상태: 작업 ID 누락·무결성 불일치 시 계속을 차단하고 파일 교체를 권장한다.
- 완료 조건: 유효한 작업 ID로 전사 중 화면에 진입하거나 새 파일 선택 상태로 돌아간다.

### F-07 전사 작업 입력 확인

- 사용자 행동: 전사 중 화면에 진입해 처리 대상 파일과 작업 정보를 확인한다.
- 입력: 작업 ID, 파일 메타데이터, 분석 옵션.
- 처리 규칙: 작업 ID 존재, 파일 접근 가능, 입력 검증 통과 여부를 다시 확인한다. 화면 새로고침 후에도 같은 작업을 조회한다.
- 출력: 파일명, 길이, 현재 단계, 적용 옵션 요약.
- 오류 상태: 만료·삭제·권한 없음·파일 접근 실패 시 처리를 시작하지 않고 업로드로 돌아가기와 다시 조회를 제공한다.
- 완료 조건: 작업 입력이 유효하고 처리 상태 조회가 시작된다.

### F-08 전사 단계별 진행 표시

- 사용자 행동: 별도 조작 없이 진행 상태를 확인한다.
- 입력: 서버 작업 상태와 단계별 진행 이벤트.
- 처리 규칙: `업로드 확인 → 화자 분리 → 음성 전사 → 전사 기반 분석 → 결과 저장` 순서로 표시한다. 실제 진행률을 알 수 없으면 임의 백분율 대신 현재 단계와 경과 시간을 표시한다.
- 출력: 현재 단계, 완료 단계, 진행 중 표시, 경과 시간. 결과 데이터는 완료 전 노출하지 않는다.
- 오류 상태: 상태 조회 실패는 작업 실패와 구분해 연결 재시도 중으로 표시한다. 일정 시간 상태가 없으면 지연 안내와 다시 조회를 제공한다.
- 완료 조건: 모든 단계가 완료되거나 명시적인 실패 상태가 반환된다.

### F-09 전사 완료 결과 및 화면 이동

- 사용자 행동: 완료 요약을 확인하고 전사 검토를 누른다.
- 입력: 완료된 전사 작업 결과.
- 처리 규칙: 전사 구간 수, 화자 라벨 존재, 시작·종료 타임코드, 구간 ID, 분석 결과 저장 여부를 검사한다.
- 출력: 완료 표시, 총 재생 시간, 전사 구간 수, `[불명확]` 및 확인 필요 건수, 전사 검토 버튼.
- 오류 상태: 필수 결과 일부가 없으면 완료로 표시하지 않고 부분 실패로 전환해 누락 항목과 다시 분석을 안내한다.
- 완료 조건: 필수 구조 검증을 통과한 결과로 전사 검토 화면에 이동한다.

### F-10 전사 오류 안내 및 다시 하기

- 사용자 행동: 같은 파일로 다시 시도하거나 업로드부터 다시 하기를 선택한다.
- 입력: 실패 작업 ID와 재시도 방식.
- 처리 규칙: 재시도 가능한 실패는 동일 원본으로 새 실행을 만들고 이전 실행 기록을 유지한다. 파일 오류는 같은 파일 재시도를 막고 교체를 안내한다.
- 출력: 실패 단계, 원인, 영향, 재시도 가능 여부, 재시도 진행 상태.
- 오류 상태: 재시도 횟수 초과·원본 삭제·서비스 장애 시 업로드로 돌아가기와 작업 기록 보존 상태를 표시한다.
- 완료 조건: 새 실행이 시작되거나 업로드 화면으로 안전하게 돌아간다.

### F-11 음성 재생 제어

- 사용자 행동: 재생·일시정지, 5초 이동, 타임라인 탐색, 3초 반복, 배속을 조작한다.
- 입력: 음성 파일, 재생 위치, 구간, 재생 속도.
- 처리 규칙: 재생 위치와 현재 전사 구간을 동기화하고 선택 구간 범위를 벗어나지 않게 한다.
- 출력: 현재·전체 시간, 재생 상태, 활성 전사 구간 강조.
- 오류 상태: 음성 로드 실패·지원하지 않는 재생 환경·범위 오류 시 재로드와 처음부터 다시 재생을 제공한다.
- 완료 조건: 요청한 위치와 속도로 음성이 재생되거나 일시정지된다.

### F-12 전사 구간 표시

- 사용자 행동: 시간순 전사를 읽고 구간을 선택한다.
- 입력: 구간 ID, 시작·종료 타임코드, 화자 라벨, 전사 원문, 신뢰도, 상태.
- 처리 규칙: 화자는 `화자 A`, `화자 B`만 표시하며 신원을 추정하지 않는다. 판별 실패·제3 화자 의심은 `화자 [불명확]`으로 표시하고 확인 필요 항목을 만든다. 들리지 않는 텍스트는 `[불명확]`으로 표시한다.
- 출력: 검색·선택 가능한 구간별 전사 카드와 근거 ID.
- 오류 상태: 타임코드 역전·중복 ID·본문 누락·허용되지 않은 화자 값은 해당 구간을 오류 상태로 표시한다.
- 완료 조건: 모든 유효 구간이 시간순으로 표시되고 음성 위치와 연결된다.

### F-13 화자 라벨 수정

- 사용자 행동: 선택 구간 또는 같은 라벨의 여러 구간을 `화자 A`·`화자 B`로 변경한다.
- 입력: 대상 구간, 변경할 화자 라벨, 일괄 적용 범위.
- 처리 규칙: 사용자가 선택한 라벨만 반영하며 실명·직책을 제안하거나 추정하지 않는다. 변경 전 값을 이력에 남긴다.
- 출력: 변경된 화자 라벨과 수정 이력.
- 오류 상태: 대상 구간 누락·허용되지 않은 라벨·동시 수정 충돌 시 저장하지 않고 재선택을 안내한다.
- 완료 조건: 라벨 변경이 저장되고 관련 화면에 동일하게 반영된다.

### F-14 전사 직접 편집 및 원문 복원

- 사용자 행동: 음성을 듣고 전사 텍스트를 직접 수정하거나 원문 복원을 누른다.
- 입력: 대상 구간과 수정문 또는 복원 요청.
- 처리 규칙: 자동 교정·문맥상 추정을 수행하지 않는다. 시스템 최초 전사, 사용자 수정문, 수정 시각을 모두 보존한다. `[불명확]` 삭제 시 사용자가 직접 확인한 수정으로 기록한다.
- 출력: 수정된 전사, 저장 상태, 수정 전후 차이와 복원 결과.
- 오류 상태: 빈 문장, 저장 실패, 동시 편집 충돌 시 로컬 입력을 보존하고 다시 저장·최신본 비교를 제공한다.
- 완료 조건: 수정본 또는 복원본이 저장되고 후속 분석의 기준 전사로 지정된다.

### F-15 불명확 구간 검토

- 사용자 행동: 표시된 구간을 반복 청취하고 유지 또는 직접 수정을 선택한다.
- 입력: `[불명확]` 구간, 음성 위치, 사용자 수정 여부.
- 처리 규칙: 시스템은 안 들린 부분을 단어로 보완하지 않는다. 미확정 상태에서는 반드시 `[불명확]`과 확인 필요 사유를 유지한다.
- 출력: 불명확 표시, 타임코드, 반복 재생, 확인 상태.
- 오류 상태: 음성으로 확인할 수 없거나 수정 근거가 없으면 해결 완료 처리를 막고 확인 필요 상태를 유지한다.
- 완료 조건: 사용자가 음성을 근거로 직접 수정했거나 `[불명확]` 유지 상태를 확인한다.

### F-16 전사 구간 분할

- 사용자 행동: 한 구간의 분할 지점을 지정한다.
- 입력: 원본 구간 ID와 분할 타임코드.
- 처리 규칙: 분할 시 새 구간 ID를 발급하고 타임코드를 겹치지 않게 나눈다. 원문과 수정 이력의 연결 관계를 보존한다.
- 출력: 분할된 두 전사 구간과 갱신된 근거 참조.
- 오류 상태: 구간 밖·시작점·종료점 분할, 너무 짧은 구간, 저장 충돌 시 분할을 취소한다.
- 완료 조건: 새 구간이 시간순으로 저장되고 기존 결과의 근거 링크가 유효하게 갱신된다.

### F-17 인용문 후보 등록

- 사용자 행동: 전사 문자열을 선택하고 인용문 후보 등록을 누른다.
- 입력: 선택 문자열, 구간 ID, 화자 라벨, 타임코드.
- 처리 규칙: 선택 문자열이 기준 전사 안에 정확히 존재해야 한다. 문구를 자동 윤문하지 않으며 생략 시 생략 범위를 기록한다.
- 출력: 인용문 ID, 원문, 화자 A·B, 원문 위치, 등록 상태.
- 오류 상태: 전사와 불일치·여러 구간에 걸친 불명확한 선택·`[불명확]` 포함 시 등록을 차단하고 사유를 표시한다.
- 완료 조건: 원문과 문자 단위로 일치하는 후보가 근거 위치와 함께 저장된다.

### F-18 사실 정보·확인 필요 항목 등록

- 사용자 행동: 전사 구간을 사실 정보 또는 확인 필요 항목으로 지정하고 사유를 선택한다.
- 입력: 전사 구간 ID, 선택 문자열, 분류, 확인 필요 사유.
- 처리 규칙: 인물·기관·수치·날짜·장소·사건 등 전사에 명시된 정보만 저장한다. 외부 검색, 보도자료 대조, 팩트체크 전송은 하지 않는다. 불확실한 내용은 사실 정보가 아닌 확인 필요 항목으로 분류한다.
- 출력: 사실 정보 목록 또는 확인 필요 목록과 근거 위치.
- 오류 상태: 근거 없는 입력·전사와 불일치·분류 누락 시 저장을 차단한다.
- 완료 조건: 항목이 하나 이상의 유효한 전사 구간 ID와 연결되어 저장된다.

### F-19 전사 검색 및 근거 이동

- 사용자 행동: 검색어를 입력하거나 결과 항목의 근거 링크를 누른다.
- 입력: 검색어 또는 구간 ID·타임코드.
- 처리 규칙: 현재 기준 전사에서만 검색하고 일치 구간을 시간순으로 표시한다. 근거 이동 시 전사와 음성 위치를 함께 맞춘다.
- 출력: 검색 결과 수, 강조된 문자열, 선택된 전사·음성 구간.
- 오류 상태: 결과 없음, 존재하지 않는 구간 ID, 음성 위치 누락 시 원인을 표시하고 전체 전사로 돌아가기를 제공한다.
- 완료 조건: 일치 구간 또는 요청한 근거 위치가 화면에 표시된다.

### F-20 검토 진행률 및 자동 저장

- 사용자 행동: 구간을 검토·수정하고 저장 상태를 확인한다.
- 입력: 구간별 검토 상태, 수정 이력, 확인 필요 상태.
- 처리 규칙: 검토 완료 수/전체 수와 미해결 수를 계산한다. 변경 후 자동 저장하며 저장 중·완료·실패를 구분한다.
- 출력: 진행률, 미해결 건수, 마지막 저장 시각.
- 오류 상태: 자동 저장 실패 시 미저장 변경을 보존하고 다시 저장 버튼과 이탈 경고를 표시한다.
- 완료 조건: 최신 변경이 저장되고 화면의 진행 수치가 서버 상태와 일치한다.

### F-21 전사 결과 내보내기

- 사용자 행동: TXT 또는 HWP용 내보내기를 선택한다.
- 입력: 기준 전사, 화자 라벨, 타임코드, 표시 항목, 파일 형식.
- 처리 규칙: 화면에 표시된 정보만 내보내며 외부 배경·추정 문구를 추가하지 않는다. `[불명확]`과 `[확인 필요]`를 그대로 유지한다.
- 출력: 다운로드 가능한 전사 파일.
- 오류 상태: 파일 생성·다운로드 실패 시 재시도와 다른 형식 선택을 제공한다.
- 완료 조건: 선택 형식의 파일이 생성되어 다운로드된다.

### F-22 전사 검토 완료 및 초안 생성

- 사용자 행동: 기사 초안 생성을 누른다.
- 입력: 저장된 기준 전사, 인용문 후보, 사실 정보, 확인 필요 항목.
- 처리 규칙: 미저장 변경을 먼저 저장하고 필수 근거 연결을 검사한다. 미해결 항목이 있으면 건수와 영향을 알린 뒤 유지한 채 진행 여부를 사용자가 확인한다.
- 출력: 검토 완료 요약과 기사 초안 생성 작업 ID.
- 오류 상태: 저장 실패·근거 ID 손상·전사 없음 시 이동을 차단하고 해당 구간으로 안내한다.
- 완료 조건: 유효한 초안 생성 작업이 시작되고 기사 초안 화면으로 이동한다.

### F-23 검토 오류 안내 및 다시 하기

- 사용자 행동: 실패 기능을 다시 시도하거나 업로드부터 다시 하기를 선택한다.
- 입력: 오류 유형, 현재 저장본, 재시도 방식.
- 처리 규칙: 재생·검색 오류는 해당 기능만 다시 시도하고, 데이터 손상은 마지막 저장본을 다시 불러온다. 처음부터 다시 하기는 현재 작업 보존 여부를 확인한 후 업로드 화면으로 이동한다.
- 출력: 오류 원인, 영향 범위, 보존된 변경, 재시도 결과.
- 오류 상태: 복구 실패 시 읽기 전용 전사와 내보내기를 제공하고 추가 편집을 차단한다.
- 완료 조건: 실패 기능이 정상화되거나 사용자가 업로드 화면에서 새 작업을 시작할 수 있다.

### F-24 기사 초안 생성 및 진행 표시

- 사용자 행동: 기사 초안 화면에서 생성 진행 상태를 확인한다.
- 입력: 기준 전사와 연결된 핵심 발언, 인용문 후보, 사실 정보, 확인 필요 항목.
- 처리 규칙: `리드 생성 → 본문 구조 생성 → 본문 초안 생성 → 근거 검증` 순서로 처리한다. 모든 생성 문장과 수치·인용은 전사 구간 ID에 연결하며 외부 배경이나 문맥상 추정을 추가하지 않는다.
- 출력: 단계별 진행 상태와 완료된 초안 버전.
- 오류 상태: 근거 없는 문장·변형된 직접 인용·해결되지 않은 참조가 발견되면 결과 노출을 막고 근거 검증 실패로 표시한다.
- 완료 조건: 리드·본문·추출 데이터의 모든 항목이 유효한 근거를 가지고 결과 화면에 표시된다.

### F-25 리드 3안 표시 및 선택

- 사용자 행동: 사실형·인용형·이슈형 중 하나를 선택한다.
- 입력: 생성된 리드 3안과 각 근거 구간 ID.
- 처리 규칙: 사실형은 명시적 사실, 인용형은 원문 인용, 이슈형은 전사에 드러난 쟁점을 중심으로 작성한다. 배경·전망·평가는 전사에 명시된 경우에만 사용한다.
- 출력: 유형별 리드, 근거 전사 ID, 선택 상태와 본문 첫 단락 반영 결과.
- 오류 상태: 3안 미충족·근거 누락·인용 불일치 시 해당 안을 표시하지 않고 재생성을 안내한다.
- 완료 조건: 근거가 유효한 3안이 표시되고 한 안이 선택된다.

### F-26 기사 본문 초안 표시

- 사용자 행동: 선택한 리드가 반영된 기사 본문 초안을 읽는다.
- 입력: 선택 리드, 권장 본문 구조, 근거가 연결된 발언·사실·인용문.
- 처리 규칙: 본문은 구조 순서대로 완성 문장으로 생성하되 전사 밖 배경, 전망, 인과, 평가를 만들지 않는다. 불확실한 정보는 `[확인 필요]`로 남기고 확정 사실처럼 표현하지 않는다.
- 출력: 문단 제목, 본문 문장, 사용한 근거 ID, `[확인 필요]` 표시.
- 오류 상태: 근거 없는 문장·수치·고유명사 또는 전사와 다른 인용문이 있으면 해당 문단을 숨기고 재생성을 요구한다.
- 완료 조건: 모든 문단이 하나 이상의 근거와 연결되고 불확실성이 보존된다.

### F-27 추출 취재 데이터 표시

- 사용자 행동: 핵심 발언, 인용문 후보, 사실 정보, 확인 필요 항목 탭을 전환한다.
- 입력: 전사 기반 분석 결과와 근거 참조.
- 처리 규칙: `검증된 사실` 대신 `사실 정보`로 표시한다. 확인 필요 항목에는 사유와 원문 위치를 붙이며 외부 검증 완료로 오해할 표현을 사용하지 않는다.
- 출력: 분류별 목록, 건수, 화자 A·B, 타임코드, 구간 ID.
- 오류 상태: 빈 분류는 0건으로 표시하고, 근거가 끊긴 항목은 결과에서 제외한 뒤 데이터 오류를 알린다.
- 완료 조건: 모든 유효 항목이 정확한 분류와 근거 위치로 표시된다.

### F-28 원문·음성 근거 대조

- 사용자 행동: 리드·문단·인용문·사실 정보의 근거 링크를 누른다.
- 입력: 구간 ID와 타임코드.
- 처리 규칙: 한 번의 동작으로 원문 전사를 강조하고 해당 음성 위치를 준비하거나 재생한다. 결과 문구와 기준 전사를 나란히 보여준다.
- 출력: 선택 근거 전사, 화자 라벨, 타임코드, 음성 재생 도크.
- 오류 상태: 구간 삭제·타임코드 누락·음성 접근 실패 시 해당 결과의 사용을 중지하고 오류를 표시한다.
- 완료 조건: 사용자가 결과에서 원문 전사와 음성까지 1회 동작으로 확인할 수 있다.

### F-29 인용문 복사

- 사용자 행동: 인용문 후보의 복사를 누른다.
- 입력: 인용문 ID와 원문 문자열.
- 처리 규칙: 화면에 표시된 직접 인용 원문만 복사하고 자동 윤문하지 않는다. 근거 ID는 내부 연결 정보로 유지한다.
- 출력: 클립보드에 복사된 인용문과 성공 안내.
- 오류 상태: 클립보드 권한 거부·인용문 무효 시 수동 선택 방법과 오류를 표시한다.
- 완료 조건: 원문과 일치하는 문자열이 클립보드에 저장된다.

### F-30 기사 초안 전체 복사

- 사용자 행동: 초안 전체 복사를 누른다.
- 입력: 선택된 리드와 현재 기사 본문 초안.
- 처리 규칙: 화면의 최신 버전만 복사하며 `[확인 필요]` 표시를 제거하지 않는다. 숨겨진 배경 정보나 미검증 데이터를 추가하지 않는다.
- 출력: 클립보드에 복사된 기사 초안과 성공 안내.
- 오류 상태: 초안 미완료·클립보드 권한 거부 시 복사를 차단하고 사유를 표시한다.
- 완료 조건: 현재 초안 전문이 표시 내용과 동일하게 복사된다.

### F-31 CMS 데스크 송고

- 사용자 행동: CMS 데스크 송고를 누르고 대상과 미해결 항목을 확인한다.
- 입력: 최신 초안 버전, 송고 대상, 사용자 확인, 미해결 항목 목록.
- 처리 규칙: 송고는 게시가 아닌 데스크 검토함 전송으로 제한한다. 자동 발행하지 않으며 `[확인 필요]`를 유지한다. 같은 버전의 중복 송고를 방지하고 전송 기록을 남긴다.
- 출력: 송고 상태, 대상, 시각, 초안 버전과 접수 ID.
- 오류 상태: 인증 만료·권한 부족·CMS 연결 실패·중복 요청 시 게시되지 않았음을 명확히 알리고 재시도를 제공한다.
- 완료 조건: CMS가 데스크 검토함 접수 ID를 반환하고 전송 기록이 저장된다.

### F-32 초안 오류 안내 및 다시 하기

- 사용자 행동: 실패 단계를 재시도·초안 재생성하거나 업로드부터 다시 하기를 선택한다.
- 입력: 오류 단계, 기준 전사 버전, 재시도 방식.
- 처리 규칙: 같은 전사로 재생성할 때 이전 초안 버전을 보존한다. 전사 변경이 필요하면 전사 검토로 이동하고, 처음부터 다시 하기는 현재 작업 보존 여부를 확인한다.
- 출력: 오류 원인과 영향, 재시도 진행 상태, 새 초안 버전 또는 이동 결과.
- 오류 상태: 반복 실패·근거 데이터 손상·서비스 장애 시 마지막 유효 버전을 읽기 전용으로 제공하고 복사·송고를 차단한다.
- 완료 조건: 새 초안이 근거 검증을 통과하거나 사용자가 전사 검토·업로드 화면에서 다시 진행할 수 있다.
